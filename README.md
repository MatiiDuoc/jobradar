# jobradar

> Realice un proyecto web el cual permita poder encontrar ofertas de trabajo o practica acorde a un CV

## Descripción

Necesitaba poder ver las mejores ofertas de trabajo, de las cuales mis skills se puedan adptar a la oferta de trabajo para asi poder tener el mejor match y poder postular, de ahi nace jobradar

## Stack

- `Laravel`
- `Inertia`
- `SQLITE`
- `typescript`
- `tailwind`
- `Php`
